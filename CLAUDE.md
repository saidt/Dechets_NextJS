# Project notes

## Technical report (`RAPPORT_TECHNIQUE.docx`)

- `RAPPORT_TECHNIQUE.docx` at the repo root is the only copy of the technical report. The owner edits it in Word and commits it; there is no online copy to keep in sync.
- To update it: pull first, then edit the .docx file in place. Keep the owner's wording and formatting; change only what the update needs.
- After an update, list what was changed so the owner can check it in Word.
- Never regenerate or replace the whole file from another source.
